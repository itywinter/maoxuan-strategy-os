# Scenario Analysis

Use for decisions with material uncertainty and asymmetric downside.

Build a small number of decision-relevant scenarios rather than dozens of decorative forecasts:

- upside / strong execution
- base / plausible middle
- downside / key assumption weakens
- tail / thesis-critical dependency fails

For each, identify drivers, cash/resource implications, constraints, and decision triggers.

Do not assign precise probabilities without a defensible basis. Scenario analysis should reveal what has to be true and whether downside is survivable, not create a false forecast.
