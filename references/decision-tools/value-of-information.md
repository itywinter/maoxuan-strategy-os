# Value of Information

## Purpose

Decide which unknowns must be resolved before commitment and which can be learned through action.

For each material unknown assess:

- decision impact if resolved
- cost/time to obtain information
- whether the decision can be staged
- whether the information arrives naturally after entry
- cost of waiting / missed window

Classify:

- **Must know before commitment**
- **Can learn after staged entry**
- **Can test through practice**
- **Low-value uncertainty**

Do not delay decisions to collect information that will not change the choice. Do not use “we can learn later” to ignore a thesis-critical unknown in a one-way-door decision.
