# Strategic Options

## Purpose

Create genuinely different paths, not three cosmetic variants of one preferred answer.

## A strategic option changes one or more of

- target customer/market
- value proposition
- capability model
- partnership model
- resource concentration
- timing
- risk profile
- revenue/economic model

For each option state:

- strategic logic
- assumptions
- resources
- upside
- downside
- trade-off / what is not done
- reversibility
- time to evidence
- falsification condition

## Option archetypes

Focus, expand, build, partner, buy, standardize, customize, defend, delay, staged entry, or exit. Use only when they fit.

## Do not force a winner

Possible output states:

- leading option
- two viable options
- depends on one unresolved assumption
- pilot first
- insufficient evidence

## Structure the choice

For high uncertainty, change price, scope, timing, conditions, staged commitment, termination rights, or partnership architecture instead of accepting a false yes/no binary.
