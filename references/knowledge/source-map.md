# Source Map

Use primary or reliable editions when exact attribution matters. This package intentionally does **not** bundle full copyrighted or historical text corpora.

## Mao-related primary reading targets

For methodological grounding, verify relevant concepts against authoritative or reputable editions of:

- 《实践论》
- 《矛盾论》
- 《反对本本主义》
- 《关于领导方法的若干问题》
- 《党委会的工作方法》
- selected writings on investigation, stages, concentration of forces, and adapting tactics to conditions

When quoting, verify exact wording and context first. Prefer paraphrase for modern adaptation.

## Modern complements

Useful bodies of practice include:

- hypothesis-driven problem solving and issue trees
- decision science: base rates, reversibility, value of information
- systems thinking: feedback loops, constraints, causal maps
- experimentation: pre-registration, baselines, thresholds, falsification
- strategy: focus, trade-offs, asymmetric competition, resource allocation

The skill should cite current external evidence when a user's real decision depends on current facts. Methodology alone never determines modern facts.
