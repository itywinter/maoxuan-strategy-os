# Mao Method Index — Modern Adaptation Map

This file maps broad methodological ideas to modern decision use. It is not a quotation source and does not imply that modern corporate recommendations were stated historically.

| Methodological idea | Modern use |
|---|---|
| 实事求是 | Evidence outranks narrative, authority, and preference |
| 调查研究 | Decision-oriented investigation and source triangulation |
| 具体问题具体分析 | Frameworks must fit the specific mechanism and stage |
| 矛盾分析 | Map interacting forces, constraints, feedback, and trade-offs |
| 主要矛盾 | Identify the current structural center of gravity when prioritization is needed |
| 矛盾主要方面 | Determine which side currently constrains the outcome more |
| 阶段性 | Priorities and KPIs change as product/market/organization matures |
| 集中力量 | Move disproportionate scarce resources to a chosen breakthrough point |
| 局部突破 / 由点到面 | Build local superiority or a beachhead, validate, then replicate |
| 实践检验认识 | Use experiments and results to test judgments |
| 根据新情况修正 | Strategy has a half-life; new facts replace old conclusions |

## Boundary

Do not force historical military or political metaphors into business. Translate the methodological logic into neutral modern terms such as stakeholder, competitor, beachhead, resource concentration, validation, and feedback loop.
