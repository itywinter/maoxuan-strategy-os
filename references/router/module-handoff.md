# Module Handoff Contracts

Downstream modules should not reconstruct reliable upstream work.

## Problem Structuring → Investigation

Provide observable phenomenon, decision objective, scope, embedded assumptions/solutions, and core problem statement.

## Investigation / Hypothesis Testing → Contradiction Mapping

Provide verified facts, surviving hypotheses, weakened hypotheses, evidence strength, critical unknowns, and candidate causal links.

## Decision Reconstruction → Root Cause

Provide timeline, actors/authority, decision and non-decision nodes, information available at each node, and evidence gaps.

## Stage Analysis → Strategic Prioritization

Provide object being staged, current stage, stage objective, evidence confidence, maturity mismatches, and exit criteria.

## Contradiction Mapping → Primary Contradiction

Provide major contradictions, structural drivers, feedback loops, candidate leverage points, and evidence status.

## Primary Contradiction / Dominant Aspect → Strategic Options

Provide current objective, stage, two sides of the contradiction, dominant aspect status, evidence confidence, hard constraints, and falsification conditions.

## Strategic Options → Strategic Focus

Provide viable options, assumptions, trade-offs, resource needs, leading option status, and unresolved decision-critical uncertainty.

## Strategic Focus → Action

Provide breakthrough point, owner, resource allocation, stop-doing list, time window, success/failure thresholds, and review trigger.

## Experiment → Review

Provide hypothesis, baseline, intervention, metrics, pre-registered thresholds, evidence, and confounders.
