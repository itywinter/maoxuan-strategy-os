# Master Router

## Objective

Use the minimum sufficient reasoning path. More frameworks do not imply better analysis.

## Step 1 — Identify intent

Classify each requested outcome when useful:

- factual — what happened?
- causal — why?
- diagnostic — what is wrong?
- priority — what matters most?
- choice — which path?
- action — how to execute?
- validation — how to test?
- review — what did we learn?

One message may contain several intents. Split them when historical explanation and current/future choice are mixed.

## Step 2 — Check problem quality

Route to problem structuring when the question:

- embeds a cause (“because sales is weak…”),
- embeds a solution (“should I fire…”),
- describes a symptom instead of the decision,
- lacks objective, scope, or timeframe needed for a useful answer.

## Step 3 — Reuse reliable state

Do not recompute a stage, fact pattern, or prior analysis unless new evidence, scope, objective, or timing makes it stale.

## Step 4 — Find the biggest decision-relevant uncertainty

Ask: **现在阻碍下一步决定的最大未知是什么？**

Choose the module that most directly reduces it.

## Step 5 — Select only the required gate/module

Typical routing:

- facts unclear → Reality / Investigation
- high safety/legal/existential risk → Constraint
- major decision might have blind spots → Completeness
- high consequence × irreversibility × uncertainty → Decision Quality
- interacting strategic factors → Strategy
- uncertainty best resolved through practice → Action
- results arrived / conditions changed → Learning

## Stage gate

If the answer to “what matters most?” depends on maturity or timing and current stage is unclear, run stage analysis before primary-contradiction analysis.

## Current-state refresh

After a historical root-cause analysis, refresh current objective, actors, resources, constraints, market, and stage before recommending current strategy.

## Non-negotiable constraints

Safety, law/regulation, existential survival, and hard irreversible obligations may run in a parallel track rather than competing to be “the primary contradiction”.

## Analysis budget

- simple/reversible: usually 1–2 modules
- medium: usually 2–5 modules
- high stakes: more only when each additional module changes the decision or evidence burden

Before every extra module ask: **如果不做这一层，下一步决策会明显变差吗？** If no, skip.

## Recursion and rollback

Return upstream when:

- new facts appear → Reality
- causal map breaks → contradiction mapping
- objective changes → problem structuring
- stage changes → stage analysis
- core strategic assumption fails → strategic options or earlier
- original problem definition collapses → hard reset

If the system returns to the same module twice without meaningful new evidence, stop and identify the lowest-cost action that can generate new information.

## Stop condition

Stop when:

- the next decision is robust enough,
- additional evidence has low value,
- the decision would not change,
- action can generate better evidence,
- another framework only restates what is already known.
