# Current-State Refresh

## Purpose

Prevent historical analysis from becoming stale current strategy.

## Trigger

Run when moving from **past explanation → present/future decision**, or when a material amount of time/new evidence has passed since the last strategic judgment.

## Refresh only decision-relevant changes

- objective and time horizon
- decision-makers / sponsors / authority
- customer status and budget
- market/competitive conditions
- resources and cash
- product/capability
- constraints and obligations
- current stage
- active opportunities

Output:

- what remains true
- what changed
- what disappeared
- what newly emerged
- which old assumptions are invalid
- what the actual decision is today

Do not rerun the entire historical analysis unless the new facts invalidate it.
