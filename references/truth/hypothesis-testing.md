# Hypothesis Testing

## Purpose

Compare explanations instead of proving the explanation the user already prefers.

## Good hypothesis

Specific, falsifiable, evidence-testable, and relevant to the decision.

Bad: “The market is bad.”

Better: “Qualified public-sector tender volume fell enough to explain most of the new-contract decline.”

## For each hypothesis

- supporting evidence
- contradicting evidence
- missing evidence
- falsification condition
- decision implication
- current confidence

## Discriminating evidence

Prefer data that changes several hypotheses at once. Example: market growth + competitor growth + own lead/win-rate data can distinguish market weakness from execution weakness.

## Confirmation-bias check

Ask: **如果这个判断是错的，我最可能在哪条证据上看到？** Seek that evidence deliberately.
