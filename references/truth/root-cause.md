# Root Cause Analysis

## Purpose

Explain a past outcome without automatically turning the associated actor or final visible symptom into the cause.

## Distinguish

- proximate cause — immediately precedes the outcome
- intermediate cause — explains the proximate cause
- structural cause — repeatedly creates the conditions for the problem

## Test each causal link

- timing: did A precede B?
- mechanism: how does A affect B?
- alternatives: what else could explain B?
- counterfactual: if A changed, would B plausibly change?
- evidence: what supports this arrow?

Avoid mechanical “five whys”. Every why must earn evidence.

## Historical versus current

Root cause answers **why the past happened**. It does not automatically identify **what matters most now**. Refresh current conditions before current strategy.
