# Investigation

## Purpose

Establish the **minimum sufficient evidence** for the next decision.

## Workflow

1. Classify available information: facts, claims, interpretations, hypotheses, unknowns.
2. Define the decision the investigation supports.
3. Create multiple plausible explanations rather than one favored theory.
4. Mark evidence gaps:
   - P0 decision-critical
   - P1 high-value
   - P2 nice-to-have
5. Prefer evidence that discriminates among multiple hypotheses.
6. Identify the strongest obtainable source for each P0 item.
7. Stop when remaining uncertainty is unlikely to alter the immediate decision or can be reduced more cheaply through action.

## Rule

Do not confuse “more information” with “better investigation”. Investigation should reduce uncertainty per unit of time and effort.
