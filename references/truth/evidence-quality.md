# Evidence Quality

Assess evidence by **directness, reliability, independence, specificity, timeliness, completeness, and incentive alignment**.

A useful rough hierarchy is:

1. primary records / measured system data / contracts / financial records
2. direct statements about the speaker's own decision or action
3. reliable independent secondary evidence
4. recollection and interpretation
5. hearsay / inferred motive / speculation

Do not use the hierarchy mechanically. A primary record can have a scope problem; a stakeholder can be the best source for their own decision but a weak source for another actor's motive.

## Triangulation

For important contested judgments, seek convergence across different evidence types rather than many repetitions of the same source.

## Motive rule

Observed effect and inferred motive are different claims. “Their action slowed the project” may be evidenced while “they intended to block us” remains unproven.
