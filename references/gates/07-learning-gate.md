# Learning Gate — 复盘与修正关

## Question

**事实出来以后，我们愿不愿意真的改？**

## Review

At each meaningful result ask:

1. What did we expect?
2. What actually happened?
3. Which assumptions were confirmed, weakened, or contradicted?
4. Did the primary contradiction, dominant aspect, or stage change?
5. What correction level is required?

## Correction levels

- execution correction — strategy still supported; execution was deficient
- tactical correction — direction supported; method changes
- strategic correction — selected path no longer supported
- model correction — problem understanding itself was wrong

Do not call every failure “execution”. Require evidence that better execution would plausibly change the outcome.

## Strategy half-life

Every material strategic judgment should have a review date, milestone, or evidence trigger. A strategy is not permanent truth.

## Hard reset

If the core problem definition or thesis collapses, return to Reality / Problem Structuring rather than patching an invalid model.
