# Strategy Gate — 求解关

## Question

**当前阶段，真正决定局面的是什么？**

## Sequence

Use only the necessary pieces:

1. Stage — what must be proved now?
2. Relationship structure — causes, constraints, dependencies, feedback loops.
3. Candidate contradictions — what opposing forces shape the situation?
4. Primary contradiction — only if structural prioritization is needed.
5. Dominant aspect — which side currently constrains the outcome more?
6. Strategic options — genuinely different paths with different resource/risk allocation.
7. Strategic focus — what receives disproportionate resources, and what stops?

## Primary contradiction test

Do not confuse the primary contradiction with the biggest, most urgent, or most painful problem. Ask:

- If this changes, how many other important problems change?
- If other problems improve but this remains, is the system still constrained?
- Is it decisive in the current stage and objective?
- Can available action affect it?
- Is evidence strong enough?

## Weak versus strong competitor

When resources are asymmetric, analyze strength by specific competitive dimension. Seek a local domain where the weaker actor can form decisive advantage, produce proof/cash/data, and replicate before the incumbent's response erodes it.

## Exclusion

A strategy must imply what **not** to pursue now. If all initiatives remain equally important, strategic focus has not occurred.
