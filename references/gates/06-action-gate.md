# Action Gate — 求效关

## Question

**下一步怎么产生结果和新的事实？**

## Use

Translate strategy into concentrated, testable execution.

## Validation ladder

Do not skip levels:

**Technical → Operational → User → Economic → Commercial → Repeatability → Scalability**.

## Experiment rule

A pilot is a question asked to reality, not a small version of a full project. Define:

- decision it informs
- hypothesis and credible alternative
- baseline/comparator
- scope and target
- evidence source
- success / modify / stop / scale thresholds
- confounders
- owner and review trigger

## Threshold governance

Set material success and kill criteria before results. If thresholds change after results are seen, do not retroactively reinterpret the completed experiment; apply new criteria to the next cycle.

## Resource concentration

A priority is real only when people, money, time, and management attention move. Create a stop-doing list and ensure the experiment is sufficiently resourced to be a fair test.

## Output

Give the user the few actions that matter, not a decorative long checklist.
