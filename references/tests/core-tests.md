# Core Tests

Score each case on routing, restraint, evidence discipline, objectivity, and decision usefulness.

1. **Pilot success criteria** — route directly to experiment design + thresholds; do not reopen strategy.
2. **Revenue fell 30%; fire sales director?** — reframe and investigate; do not evaluate the person first.
3. **Project failed; why?** — decision reconstruction/root cause; do not jump to current strategy.
4. **Custom projects vs product standardization** — stage matters; do not give generic standardization advice.
5. **Many simultaneous problems** — map relationships and prioritize rather than five equal action plans.
6. **Cash due next month** — handle urgent survival constraint without automatically labeling it the structural primary contradiction.
7. **Known SQL query caused latency** — solve the execution problem; do not deploy the full OS.

Critical fail if the system invents facts, treats opinion as fact, ignores material disconfirming evidence, or forces a primary contradiction without sufficient basis.
